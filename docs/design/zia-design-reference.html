The single source of truth for ZiA's visual language. Every token below is defined in Sources/Jarvis/UI/Theme/ZiaTheme.swift and consumed by the components in Sources/Jarvis/UI/Components/. The state images are renderings of the actual SwiftUI views (Jarvis --render-ui), so this board cannot drift from the shipped UI without a test noticing.

Every animation is routed through ZiaMotion.respectingReduceMotion, which returns nil when macOS Reduce Motion is on.

4. Presence language

ZiA's state is communicated by one sphere whose motion changes meaning per state. Idle is static by design — nothing animates when nothing is happening, so idle costs no CPU.

Idlestatic · calm
Listeningoutward sonar rings
Understandingconverging ring
Thinkingrotating arc
Workingorbiting satellite
Speakingamplitude halo
Donestatic
Errorstatic
Stoppedstatic

Mapping rule: ZiaPresenceState.resolve(phase:appEnabled:stopped:) maps the real InteractionPhase reported by the agent/voice pipeline. An explicit user stop always wins over a stale backend phase.

8. Rules this board encodes

RuleHow it is enforced
No fake stateEvery status surface reads live state (provider probe, TCC status, task state machine, mic RMS).
No fake motionThe energy field renders measured microphone energy only; the idle presence is a 12 fps breath, and the presence freezes entirely while the HUD is hidden.
Focus is never stolenThe overlay is a non-activating panel; the main window opens only from an explicit user action.
Reduced motionAll animation passes through ZiaMotion.respectingReduceMotion.
Light and dark paritySemantic dynamic colours; a test asserts they differ per appearance.
No magic numbersSpacing, radius, typography, motion and metrics come from the token namespaces.
